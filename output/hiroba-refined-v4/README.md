`index.html` は画像・CSS・JavaScriptを内包した単独の比較用モックです。本番サイトは変更していません。

ユーザーの「もう少し細かく」「ドット柄にこだわらなくていい」「今のHPぐらいのテイストで」という修正を反映。角ばったピクセル表現をやめ、実際のHPのSVGを直接土台にしています。

- 校庭・校舎・色：公開用/index.html に埋め込まれた既存の学校SVGを使用。
- 4人：src/ill/kyara の元SVGを複製し、前髪、目、口、靴底、服、小物を少し調整。
- UI：細い黒線、紙色、緑・朱・紺・黄を引き継ぎ、小さな丸みと控えめな影に。
- 学級会・運動会・児童会・クラブを選ぶと、対応する場面を拡大。
- 「4人の紹介」から、キャラクターを大きく確認できます。
- 既存の行き先、メニュー、サイト説明を維持。紹介文は今回の試作のための文案です。

主な成果物：index.html、gakkatsu.svg、gyoji.svg、jidokai.svg、club.svg、characters.svg、school.svg。PNGはSVGからレンダリングした確認用です。SVGは拡大しても輪郭が荒れません。
