# 特活広場 キャラクターポーズ集

承認済みの characters-refined-v6 の顔・服・色を用いた、24の個別ポーズと3つの集合ポーズです。

- all-poses.png：全24ポーズ一覧
- sheet-groups.png：肩を組む／ようこそ／ありがとう
- homepage-entries.png：HPの4つの入口への割り当て案
- sheet-*.png：各キャラクターの6ポーズ
- その他のPNG：背景透過、個別素材。SVGは拡大・編集用です。
- manifest.json：ファイル名と用途一覧

HPの項目は src/hiroba.html と build.py の入口定義を参照しました。サイト本体は変更していません。
