# 特活広場・学校全景 第7案

承認された `../characters-refined-v6/` の4人を、現在のHPの学校全景へ反映した画像案です。公開中のサイトや src/ は変更していません。

- `school.png` / `school.svg`：空も含む全景、3200×1200。HPの背景として使える元の比率。
- `school-close.png` / `school-close.svg`：校舎と活動を見やすくした切り出し、3200×890。
- `detail-class.png`：学級会。
- `detail-events.png`：学校行事。
- `detail-council.png`：児童会。
- `detail-club.png`：クラブ活動。

元の空・校舎・体育館・木・フェンス・校庭の色を維持。学級会の机、リレーコースとバトン、児童会の発表台、クラブの工作机を整理しました。小さな子どもたちも4人と同じ前髪・楕円の目・線の笑顔に合わせています。4人の口、行人の旗の棒、児童会ちゃんの肩は承認済みの第6案を使用しています。

SVGを直接編集して作成し、SharpでPNGへ描画しています。新たな画像生成は使用していません。`build_image.py` で現在のHPの部品と背景からSVGを再生成できます。再生成時の元データは、その時点の build.py と src/ill/buhin/ です。

確認：SVG構文、外部画像参照なし、使用色、PNG寸法、全景と4場面の目視。最終PNGは3200px幅で出力。サイトへの組み込みと公開は行っていません。
