# 特活広場：人型マスコットのHP試作

承認された `mascots-humanoid-v4.png` のテイストを学校の背景とUIに広げた案です。
追加の希望に合わせ、背景はHPを参考にしたさらに遠い構図へ変更しました。人数を増やし、水やり、落ち葉掃き、ノート運びなどの細部を加え、懐かしい学校の絵本を意識した配色と線にしています。UIも紙色・落ち着いた朱・濃い茶色の輪郭へ寄せました。

- `index.html`：画像・CSS・JavaScriptを内包した1ファイルの試作。開く際の外部読み込みはありません。
- `school-world-retro.png`：現在の人数を増やしたレトロな遠景案。
- `school-world-distant.png`：一つ前の遠景案。比較用に保持。
- `school-world.png`：前の近景案。比較用に保持。
- `mascots.png`：承認された4人。
- `page.template.html` と `build_preview.py`：編集・再生成用。
- `prompts.json` と `prompt-distant.json`、`prompt-retro.json`：内蔵画像生成に渡したプロンプト。
- `validation.json`：静的検証結果と表示検証の制限。

## UI

「みんなの実践を見る」「実践を送る」を主な入口にしました。
4人のカードには、実際のHPの「ちょっと聞きたい・知りたい・試したい・伝えたい」を使用しています。
色は各キャラクターに対応し、太い輪郭・丸い角・平たい影を共通にしています。

背景の5つの切り替え（全景と4つの活動）、8つの行き先メニュー、サイト説明ダイアログを実装しました。
リンクは既存の公開HPに移動します。データ送信はリンク先のフォームを操作した場合のみです。
本番のソース・公開用ファイルにはこのデザインを反映していません。

## 元の画面の診断

title-design の14項目を確認しました。適用できる指摘は以下です。

- 大きな全景の中では人物が小さいため、全景と、人物の大きい案内カードを分けました。
- 既存HPのスクリーンショットでは雲の輪郭とコピーが交差していました。試作では文字をイラストの外に配置しています。
- 元のHPの8つの行き先と4人の案内は、スクロール先に分散していました。入口に主要な行き先を並べ、8つを一覧できるメニューも用意しました。
- 元からある色分けを維持。本文リンクや脇役のUIまで無関係な多色にしていません。
- ゲーム用の進捗・セーブ・初回プレーに関する項目はこの情報サイトには該当しません。
- 元の画面の実際の要素寸法とタップサイズは未測定のため、不具合とは断定していません。

## 確認したことと制限

公開用HTMLを参照して、リンク先ファイルとアンカーの存在を確認しました。
埋め込み画像、代替テキスト、ID重複、初期選択、外部スクリプト不使用、およびJavaScriptの構文を確認しました。

ブラウザーのURLポリシーによりローカル試作の表示が拒否されました。
別の方法でこの拒否を回避することはしていません。
そのため、title-design の3サイズ（1470×830、1280×700、1180×760）の実測、重なり検査、実ブラウザーでの操作確認は未実施です。
スクリーンショットや実測済みという主張は提供していません。
狭い画面はCSSで縦並び・スクロールを許す構成にしていますが、実機での最終確認が必要です。
