# TOKKATSU広場：立体版 / ドット絵版

`index.html` をブラウザーで開くと、上部の「立体キャラクター」「ドット絵」でサイト全体の絵柄を切り替えられます。初期表示は立体版です。文章・レイアウト・行き先を共通にしています。

- 立体版：指定された4人のキャラクター、新しい立体の校庭、丸いボタン、厚みのある影。
- ドット絵版：細かさを調整した既存の第2案、角ばった枠、くっきりした影。
- 背景下のボタンで学級活動・学校行事・児童会活動・クラブ活動へ拡大できます。
- 行き先メニュー、サイト説明ダイアログ、既存HPへのリンクを含みます。

画像をすべて埋め込んだ単一HTMLです。閲覧中の切替に通信は不要です。行き先リンクは現在の公開HPを開きます。本番サイトは変更していません。

## ファイル

- `school-3d.png`：ドット絵の学校配置に合わせて生成した新しい立体版の背景。
- `mascots-3d.png`：今回指定された既存の4人。
- `pixel-sheet.png`：既存のドット絵第2案。SVGのviewBoxで背景と4人を表示。
- `prompt.json`：今回の背景生成に用いたプロンプトと参照画像。
- `theme.css` / `theme.js`：見た目と切替の定義。
- `build_preview.py`：以前のHPモックの共通内容からHTMLを組み立てるスクリプト。
- `validation.json`：静的確認の結果。

再生成：`python3 output/site-style-comparison/build_preview.py`

画像寸法、SVG参照、ID重複、テーマ定義、JavaScript構文、公開用HTML内のリンク先アンカーを確認済みです。ローカルプレビューはブラウザーのURL安全ポリシーで拒否されたため、自動表示・レイアウト・クリック操作の確認は未実施です。比較用の未公開試作です。
