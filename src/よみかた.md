# src/ の中身と、中身の足しかた

## いちばん大事なこと

**直すのは `src/` の中だけ。`公開用/index.html` は手で触らない。**
`公開用/index.html` は `build.py` が毎回まるごと書き直すので、手で直しても次のビルドで消えます。

src/style-simple.css … 見た目ぜんぶ（簡素版・墨1色）
src/storage.js       … 保存はここだけ（将来ネイティブ化するときはここだけ差しかえる）
src/boot.js          … 描く前に表示モードと言語を決める
src/body.html        … 5タブの中身ぜんぶ
src/app.js           … 動きぜんぶ
src/tobira.html      … とびら版（入口の試作）の中身   ★段1
src/style-tobira.css … とびら版の見た目だけ            ★段1
src/ill/*.svg        … イラスト1枚＝1ファイル          ★段1

### 資料（指導案・スライド・板書）を、ページの中で開く　★2026-09-21

PDFは埋めません（端末しだいで開かない／外に通信が飛ぶ）。
**1ページ＝1枚の画像にして、HTMLの中に入れます。**だから外に1本もつながりません。

1. `src/shiryo/◯◯/` を作り、`01.webp` `02.webp` … と**名前の順**に置く
2. .md に1行 `shiryo: 指導案|◯◯`

PDFから画像にするには（横1000px・WebP・品質60。22ページで約1.9MB）：

```bash
python3 -m pip install --user pymupdf
python3 -c "
import pymupdf, os
d = pymupdf.open('もとの.pdf'); os.makedirs('src/shiryo/◯◯', exist_ok=True)
for i, pg in enumerate(d):
    z = 1000 / pg.rect.width
    pg.get_pixmap(matrix=pymupdf.Matrix(z, z), alpha=False).pil_save(
        'src/shiryo/◯◯/%02d.webp' % (i+1), format='WEBP', quality=60, method=6)
"
```

| 上限 | |
|---|---|
| 画像1枚 | 500KB |
| 資料1件（1フォルダ） | 8MB |
| 1ページに入る合計 | 16MB |

超えると**ビルドが止まります**。要らないページは、ファイルごと消せば出ません。

`shiryo:` に `https://…` を書くと、いまも**外のタブが開くリンク**になります（「外部」と出ます）。
ページの中で開きたいものは、フォルダに置いてください。
`naiyo` も同じで、4つ以外を書くと止まります。**空でも止まります**
（どのカードにも集まらない実践を作らないため）。

## 広場で出た悩みを1件足す　★2026-09-21

悩みは .md ではなく、`build.py` の **`NAYAMI` の表**に1行書きます。
ここ1か所に書くと、**2か所に出ます**。

1. 「学ぶ」の**お悩み別の入口** … 学習過程の段階につながる悩みだけ
2. 「4つの内容」の**カードの中** … その内容の悩み、ぜんぶ

```python
NAYAMI = (
    ('gakkyu',  '学級会が話し合いにならない', '2'),   # ②が開く
    ('jidokai', '児童会を任された',           ''),    # 行き先はまだ無い
)
```

| | 何を書くか |
|---|---|
| 1つめ | 4つの内容のどれか（`gakkyu` `gyoji` `jidokai` `club`） |
| 2つめ | 悩みの言葉。**先生が言うとおりに**。言いかえない |
| 3つめ | 行き先。`'1'`〜`'5'` は学級活動(1)の学習過程の段階。**無ければ空** |

「学ぶ」のお悩み別の入口に出るのは、**上から `NAYAMI_IRIGUCHI` 件**（いまは6件）だけです。
ぜんぶ出すと、入口が入口の役をしなくなります。カードの中には、ぜんぶ出ます。

### LINEから写すときの約束

いま入っている24件は、LINEオープンチャットの 8/9〜9/21 のやりとりから写したものです。
**ここを外すと、書いた人が特定されます。**

1. 発言をそのまま引用しない。**悩みの言葉に言いかえる**
2. 発言者・学校・地域・日付は**一切載せない**（表にも持たせない）
3. 1人の個別事情が分かる書き方にしない。**同じ困りごとの一般形**にする
4. 答えを置けていないものも消さない。**「まだ答えが無い」ことが情報**です

**行き先が空でも、そのまま出します。**
「LINEで聞く」の破線の札になって、答えがまだ無いことが見えます。
**空の悩みを隠さないのが、この表の要です。**どこが薄いかが、4枚のカードで一目で分かります。

同じ言葉を2回書く／4つ以外の内容を書く／行き先に1〜5以外を書くと、**ビルドが止まります**。

## グッズを1点足す・配れるようにする

1点＝`src/goods/` の1ファイル。ファイル名がそのまま id です（`card.md` → `card`）。
並ぶ順は `order:` の数字の小さい順。ファイル名を `_` で始めると出ません。

**いまは6点すべて「準備中」です。** 配れるようにするには、その .md に
`pdf:` と `docx:` のURLを書きます。

```yaml
pdf:  https://……/teian-card.pdf
docx: https://……/teian-card.docx
```

- 両方書く → ボタンが「PDF・Word」に変わる
- 片方だけ → 書いたほうだけ
- どちらも空 → 「準備中」のまま

**「使う実践」の逆リンクは自動です。** 実践側の `goods:` に id を書けば、
グッズの側に「使う実践：◯◯」が出ます。グッズ側には何も書きません。

`icon:` に書くのは `src/body.html` の `<symbol id="g-…">` の id です
（`g-card` `g-post` など）。**グッズ本体の id（`goods-card`）とは別物**なので注意。
同じ id を2つ作るとリンクが別の場所へ飛ぶため、ビルドが止まります。

「困りごと・意見を送る」「実践・板書を送る」の行き先は、
**`build.py` の `LINKS`（39〜40行目）1か所だけ**で決まります。

```python
LINKS = {
    'FORM_IKEN'  : 'https://forms.gle/……',
    'FORM_JISSEN': 'https://forms.gle/……',
}
```

いまは、どちらも既存の「ご依頼・修正フォーム」を仮に指しています。
専用のフォームは `意見・実践フォーム作成.gs` で作れます（作り方はファイルの頭に書いてあります）。
作ったら、出てきた2つのURLをここに貼って、ビルドをやり直すだけです。

`src/body.html` の中では `{{FORM_IKEN}}` `{{FORM_JISSEN}}` と書きます。
`LINKS` に無い `{{…}}` が残っていると、**ビルドが止まります**。

## 検問

`build.py` は、次のどれかに当たるとビルドを**止めます**（中途半端なものを出さない）。

- `share: true` が無い … 出さずにとばす（止めはしない）
- `効き目` `自分の考え` `返し` `分野` の欄がある … 優アンテナの欄なので**止める**
- `src/_ngword.txt` の語が出力に出た … **止める**
- `url` が http(s) で始まらない … **止める**
- 相対パスの `src=` `href=` が残った … 外部ファイルができてしまうので**止める**
- **同じ id が2つ以上ある** … リンクが別の場所へ飛ぶので**止める**
- **`LINKS` に無い `{{…}}` が残っている** … **止める**
- **実践の `goods:` に無いグッズの id がある** … **止める**
- **実践の id（ファイル名の後ろ）が2件で同じ** … **止める**

`python3 build.py --check` は、書かずに結果だけ見ます。

### とびらの検問

| 止める条件 | 何を防ぐか |
|---|---|
| SVGに `width=` `height=` がある | スマホでの崩れ |
| `viewBox` が 240 か 120 の正方形でない | 並びのズレ |
| SVGに `<title>` が無い | 読み上げで無言になる |
| SVGの `id` が `ill-` で始まっていない | 本体とidが重なってリンクが迷子 |
| SVGに `<image` `data:image` `<text` `<style` がある | 写真混入・書体依存 |
| 場面（240）に `rx="20"` か `stroke-width="4"` が無い | 3枚の画風がそろわない |
| 空（120）に全面を覆う四角がある | 浮かばずにシールに見える |
| 決めた5色の外の色が出た | 画風のばらつき |
| SVG1枚が 6KB を超えた | 容量 |
| `--sora-h` が 50svh を超えた | 1枚目のカードが画面から落ちる |
| CSSに `prefers-reduced-motion` が無い | 動きが止まらない |
| 決めた色の組み合わせが 4.5:1 未満 | 読めない |
| `tobira.html` が 300KB を超えた | 起動が遅い |
| （本体と共通）相対パス・id重複・NGワード・`{{…}}` 残り | — |

## ページの分け方　PAGES 1か所

2026-09-21から、公開するのは**4枚**です。`build.py` の `PAGES` が、その全部を決めます。

| ファイル | 名前 | 入っている節 |
|---|---|---|
| `index.html` | ホーム | （8つの札。節は入りません） |
| `shiru.html` | 知る | `about` `yotsu` |
| `manabu.html` | 学ぶ | `manabu` `jissen` |
| `atsumaru.html` | 集まる | `ima` `news` `kai` `okuru` |

`src/hiroba.html` は、いままでどおり**1枚ぶんの原稿**です。ここに `manabu.html#…` とは書きません。
節を足したら `<section class="sec" id="◯◯">` で書いて、`PAGES` のどれかに `'◯◯'` を入れるだけ。
**どこにも入れ忘れると、ビルドが止まります**（無い節を入れようとしても止まります）。
`SETSU_NA` に日本語の名前も足してください。

ページをまたぐリンクは、`tsunagi_naosu()` が組み上がってから機械で張りなおします。
行き先の無い `<a href="#◯◯">` が1本でもあれば、ビルドが止まります。

### ホームの札

`HOME_FUDA` が8枚を作ります。1枚＝（節のid, 絵のたね `k`／`b`, 絵の名前, 短い1行）。
**数は `home_kazu()` がその場で数えます。**手で数字を書かないでください（足したのに古い数が出る、が起きます）。

### 前のURLを生かす表

1枚だったころの `index.html#jissen` のようなURLで来た人は、`SAKI`（`{{SAKI}}` に差しこまれる表）で
いまその節がいるページへ送られます。`PAGES` を直せば、この表も勝手に付いてきます。

### 上げるとき

GitHubには**4ファイルとも**同じ場所に上げてください。`index.html` だけだと、押した先が404になります。
