# 困りごと（src/komari/）

サイトの「ちょっと聞きたい」から送られた1件が、ここに1ファイルずつ増えます。
**誰の目も通りません。**送られたら、そのまま komari.html に出ます。

1件のかたち（Apps Script が作ります）

```
---
share: true
date: 2026-09-21
grade: 3〜4年
---
困っていることの本文。何行でも。
```

  share: true が無いものは出しません。
  date が 2026-09-21 の形でないものも出しません。
  src/_ngword.txt の語が入っているものも出しません。

★ここだけは、当たっても **ビルドを止めません**。その1件を出さないだけです。
  1件の困りごとでサイト全体が止まると、ほかの人にも分からないからです。

消すときは、このフォルダからファイルを消してください。
知らせのメールの［すぐ消す］でも消えます。
