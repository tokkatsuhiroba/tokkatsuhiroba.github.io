# LINEから書き出した困りごと（24件）— 控え

2026-09-22 まで、この24件は `build.py` に直接書いてあって、
サイトを開いた人には**最初から全部そろって見えて**いました。

それをやめました。悩みは **送られたものが溜まっていく** 形にします。
「最初から誰かが用意したもの」ではなく、**みんなで作り上げているもの**にするためです。

**このファイルは出ません**（名前の頭が `_` なので `build.py` が飛ばします）。
ここから1件ずつ `.md` にすれば、また並びます。LINEで新しい困りごとが出たときも、
同じやり方でここに足していけます。

---

## 出どころと、載せるときの約束

LINEオープンチャット「みんなの特活ひろば（仮）」の 8/9〜9/21 のやりとり（1750件）を
読んで、**実際に出ていた困りごとだけ**を書き出したものです。

1. 発言をそのまま引用しない。**悩みの言葉に言いかえる**
2. 発言者・学校・地域・日付は**一切載せない**
3. 1人の個別事情が分かる書き方にしない。**同じ困りごとの一般形**にする
4. 答えを置けていないものも消さない。**「まだ答えが無い」ことが情報**です

## 1件を出す形

`src/komari/2026-09-22_line-gidai-denai.md` のように作ります。
ファイル名の `_` から後ろが、そのまま URL の id になります。

```
---
share: true
date: 2026-09-22
title: 議題が出てこない
naiyo: gakkyu
saki: 1
---
議題箱を置いても、なかなか入りません。
どうすれば、子どもから出てくるようになりますか。
```

- `title` … 札に出る短い言葉。無ければ本文の1行目から自動で作ります
- `naiyo` … `gakkyu` / `gyoji` / `jidokai` / `club`。足すと4つの内容のカードにも並びます
- `saki` … `1`〜`5`。足すと**押せる札**になり、学習過程のそこが開きます
  ＝ **この悩みに答えが付いた、という印**です
