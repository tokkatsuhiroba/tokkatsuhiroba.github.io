# src/nittei ── サイトから送られた研究日程

ここに入る `.md` は、**ホームの「研究日程」から送られたもの**です。
Apps Script（`板書を受けとる.gs` の `kind: 'nittei'`）が1件＝1ファイルで置きます。

こちらで調べて手で書くぶんは、これまでどおり **`src/app.js` の `EVENTS`** です。
出どころが違うので、混ぜていません。こよみの上では、日付順に一緒に並びます。

## 1件の形

```
---
share: true
date: 2026-09-22
title: 学級活動部 検証授業（学級活動(1)）
org: 東京都小学校特別活動研究会（都小特活）
days: 2026-10-09
deadline:
venue: 世田谷区立山野小学校
place: 東京都世田谷区
apply: 事前登録は不要です
url: https://tosho-tokkatsu.tokyo/
by: 送ってくださった先生
---

6年 学級活動(1)／14:15〜　講師：帝京大学教育学部 教授 安部恭子 先生
```

| 欄 | |
|---|---|
| `share: true` | **これが無いと出ません** |
| `date` | 送られた日（並べるためだけ。こよみには出ません） |
| `title` | 会の名前。**必須** |
| `days` | 当日。2日開催は `2026-08-07\|2026-08-08` と `\|` でつなぎます。**必須** |
| `deadline` | 申込の〆切。入れると、こよみに点線の丸が出ます |
| `apply` | 「事前登録は不要です」など |
| `url` | 案内ページ。`http(s)` 以外は落とします |
| `by` | 名前を出してよいと押した人だけ入ります。無ければ「送ってくださった先生」 |
| 本文 | **何をやる会か、の1行。10字以上。必須**（原則③＝名前とURLだけ並べない） |

## 直すとき・消すとき

- 中身を直すなら、このフォルダの `.md` を手で直してください
- 消すなら、ファイルごと消します（知らせメールの［すぐ消す］でも消えます）
- **日が過ぎたものは、こよみから自動で消えます。**ファイルは残ります

## 止まらない作りになっています

`build.py` の `load_nittei()` は、**変な1件があっても止まりません**。
その1件だけ出さずに、ビルドの終わりに「とばした日程… 〜」と理由を出します。
`src/app.js` の `EVENTS` のほうは、これまでどおり検問で止まります。
