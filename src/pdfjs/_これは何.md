# pdfjs — PDFをブラウザの中で絵にする道具

送られてきたPDFを隠す（塗る）ために使います。**PDFを選んだときだけ**
取りに行きます。ふつうにページを読むだけの人は、1バイトも読みません。

| | |
|---|---|
| 出どころ | https://github.com/mozilla/pdf.js （Apache License 2.0） |
| 版 | pdfjs-dist 4.10.38 |
| 取った所 | https://cdn.jsdelivr.net/npm/pdfjs-dist@4.10.38/build/ |
| 中身 | `pdf.min.js`（本体）／`pdf.worker.min.js`（裏で動くほう） |

## なぜ、CDNから読まずに ここに置くのか

学校のネットワークは、外のCDNを止めていることがよくあります。止められると
**PDFが送れなくなります**。同じ置き場から配れば、サイトが見えるなら必ず読めます。
外の誰かに頼らないので、その先が変わっても壊れません。

## なぜ .mjs ではなく .js なのか

GitHub Pages は `.mjs` を JavaScript として配ってくれないことがあります。
そうなると、読みこむところで止まります。`.js` なら確実です。
中身は元のまま（ES モジュール）で、名前だけ変えてあります。

## 新しくするとき

1. 上のURLの版だけ差しかえて、2つとも落とす
2. `pdf.min.js` `pdf.worker.min.js` の名前で、このフォルダに置く
3. `python3 build.py` → 公開用/pdfjs/ に写ります
4. PDFを1つ送ってみて、ページが出て、塗れて、送れることを確かめる
