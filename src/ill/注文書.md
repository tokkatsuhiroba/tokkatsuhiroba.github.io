# 広場の部品づくり（Codexへの注文書）

**方向A：入口は「広場の絵1枚」。**正方形3枚はやめました。

---

## なぜ部品に分けるのか

`hiroba.svg`（広場を1枚で頼んだもの）を測った結果です。

| | Codexの広場 | アスザック（見積もり） |
|---|---|---|
| 線の太さ | **5種類**（3 / 4 / 5 / 6 / 72） | 実質**1種類** |
| 色 | **12種類** | 6〜7種類 |
| 図形の数 | **100個** | 見どころ約70か所 × 10〜20図形＝**700〜1400個** |

**どのAIでも、1回の注文で800図形は出ません。**モデルを変えても同じです。

でも `<use>` を使えば、**こども1人を20回置けば20人**になります。
図形は増えず、容量もほとんど増えません。**これがSVGの本当の強みです。**

だから、**小さい部品を1個ずつ**作ります。
Codexは小さい絵が上手いので（運動会の絵は88pxまで縮めても読めました）、
下手なのではなく、**注文が大きすぎただけ**です。

`hiroba.svg` は捨てません。**構図の下敷き**として残します。

## 決まりは3つだけ

### ① 線の太さは「2.5」の1種類だけ

太さで遠近を出さない。**これがいちばん効きます。**
太さがバラつくと、絵ではなく「図形を組み立てたもの」に見えます。

`stroke-width="2.5"` 以外が1つでもあれば、ビルドが止まります。

**なぜ 2.5 か**（9/21に 4／3／2.5／2／1.6 を並べて実測しました）

| | 見え方 |
|---|---|
| 4 | 黒が勝って重い。絵が暗くなる |
| 3 | まだ少し重い |
| **2.5** | **輪郭は効いているのに、服の色が主役になる。明るい** |
| 2 | 軽いが、広場に置いたとき輪郭が弱る |
| 1.6 | 置いた大きさ（26px）で**輪郭が消えかける** |

### ② 色は、地と墨のほかに7色だけ

| 色 | 役 |
|---|---|
| `#FCFBF7` | 地（紙） |
| `#1C1C1A` | 墨（線） |
| `#A9E1F5` | 空 |
| `#2FBA68` | 緑（山・木） |
| `#1F5C3F` | 濃い緑（影・黒板） |
| `#D2552A` | 朱（旗・こども） |
| `#E8C547` | 黄（日ざし・地面） |
| `#3A6EA5` | 紺（屋根・式） |
| **`#F6D8B8`** | **肌（顔と手だけ）** |

**茶色はありません。**木の幹や机は、濃い緑か黄で描きます。
この9色の外が1つでも出たら、ビルドが止まります。

**★顔に地の色 `#FCFBF7` を使わないでください**（9/21に直しました）。
顔が紙と同じ色になると、**顔に穴が空いて見えて、怖くなります**。
顔と手は必ず `#F6D8B8` です。

### ③ 手足も「塗り＋線」で描く（線1本にしない）

手足を `stroke` 1本で描くと、胴（幅26の面）に対して線が2.5しかなく、
**虫の脚のように見えます**（9/21に直しました）。

- **腕**：幅 7.5・長さ 20 の角丸（`rx=3.75`）を、肩から 10度ひらいて置く。肌色
- **脚**：幅 9・長さ 22 の角丸（`rx=4.5`）。肌色
- **靴**：白 `#FCFBF7`。**脚の丸い底を完全に覆う形**にする
  ← ここが大事。靴が小さいと、脚の丸い底が靴の間から覗いて気持ち悪くなります
- 胴・腕・脚・靴は、**どれも「塗り」があって、まわりに 2.5 の線**

顔の目・口・髪だけは `stroke="none"` の塗りです（線で描くと潰れるため）。

### ④ 接地線は、viewBox の下端から **8** 上

置くときは**下ぞろえ**にします。だから足もと（地面に着く線）の位置がそろっていないと、
ある子は浮き、ある子は沈みます。

```
viewBox の高さが 90 なら、足もとは y=82
viewBox の高さが 108 なら、足もとは y=100
```

### ⑤ ★いちばん間違えやすい：**実寸で描く**

広場の canvas は **2400 × 1200** です。
部品は、**その広場の中で実際に置かれる大きさ**で描いてください。

**こどもの身長 90 が、すべての物差しです。**

| | 実寸 | こども何人ぶん |
|---|---|---|
| こども | 90 | 1.0 |
| 先生 | 108 | 1.2 |
| 木 | **220** | 2.4 |
| 校門 | 220 | 2.4 |
| 体育館 | 450 | 5.0 |
| 校舎 | 500 | 5.6 |

置くときに**拡大も縮小もしません**（`<use x y>` だけ。width/height は付けません）。

**これをやらないと、線の太さ4がそろいません。**
小さく描いた部品を引き伸ばせば線は太く、大きく描いた部品を縮めれば線は細くなります。
①の決まりが、ここで崩れます。

## 届いたら

**`src/ill/buhin/` に、指定の名前で保存 → 検問。**

```bash
npx svgo src/ill/buhin/ko-tatsu.svg -o src/ill/buhin/ko-tatsu.svg
python3 build.py --buhin
```

`--buhin` は、部品だけを測って表に出します。

```
  部品 3個。線の太さは全部 4、色は決めた8色の中だけです。
     名前               実寸        大きさ  図形  色数
     ko-tatsu           44×90       0.6KB    8   3
```

規律を外していれば**止まって、どこが違うかを日本語で言います。**
とくに **線の太さが2種類以上あれば、その場で止まります。**

配置（どこに何を何個置くか）は、部品がそろってからこちらで書きます。
**座標を決めるのはコードの仕事で、絵の仕事ではありません。**
